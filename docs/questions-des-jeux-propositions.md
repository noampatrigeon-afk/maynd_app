# Questions des jeux : propositions (30/09/2026)

> **Appliqué le 30/09 :** toutes les propositions A sont en place, dans `src/scripts/34-questions-des-jeux.js`. C'est ce fichier qui fait foi. Pour changer une question, c'est là qu'il faut la modifier ; les variantes B restent ici comme réserve.

Pourquoi ce document :
- les questions actuelles n'ont pas de point d'interrogation ;
- plusieurs sont trop vastes pour être comprises seules, par exemple Sol, question 3 : « Ce qui déclenche le plus souvent. » Une personne qui revient après une interruption ne sait plus de quoi on parle.

Règles appliquées partout :
1. **Une vraie question, avec son point d'interrogation.**
2. **Le sujet est rappelé dans la question** (tes nuits, au travail, le stress…), pour qu'elle se comprenne toute seule.
3. **Les réponses existantes ne changent pas.** Chaque question a été relue avec ses réponses pour vérifier qu'elles s'enchaînent bien.
4. Tutoiement, phrases courtes, aucun mot clinique. Les accords au féminin se font à l'affichage : chaque nouvelle tournure recevra sa règle dans `accordFeminin()`.

**Comment valider :** A est ma recommandation. Les questions marquées ★ sont celles qui étaient trop vastes : elles ont une variante B. Réponds par exemple « tout A, sauf Sol 3 : B, Neo 2 : B, et Atlas 2 : [ta version] ».
